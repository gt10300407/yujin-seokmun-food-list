변경 내용

공개 화면제목 `유진 석문의 맛집 리스트`, `to 소연누나`, Food Tour 로고, 레트로 색상, 둥근 제목 글씨체
맛집 카드식당 10곳, 종류 필터, 카드 전체 너비를 쓰는 작은 한 줄 코멘트와 `카카오맵 열기 ↗`. 코멘트 전체를 줄바꿈·말줄임 없이 표시
사진10곳에 사진 29장 연결. 상세 상단에서 한 장씩 스와이프·이전·다음 버튼·전체 화면 확대. 사진이 없으면 `사진 없음` 표시
관리 화면이 Mac에서 맛집 추가·수정·삭제, 주소·종류·메뉴·한줄평 입력, 사진 업로드·정렬·삭제. 저장 후 커밋·푸시 버튼으로 식당 데이터와 사진만 GitHub에 올림

검증 결과

목록과 화면로컬에서 식당 10곳 모두 사진 카드와 한줄평 표시 확인. 320px·390px·1440px에서 코멘트 10곳 모두 줄바꿈·잘림 없음. 로고와 개수 겹침 없음. 모바일 가로 넘침 없음
사진 슬라이드실제 사진 3장·2장 식당에서 슬라이드 전환, 이미지 로드와 전체 화면 확대 확인
상태와 접근성로딩·빈 목록·데이터 오류 상태, 키보드 초점·44px 지도 링크·움직임 줄이기 확인
관리 및 배포임시 맛집 추가·사진 업로드 후 로컬 공개 화면에 11번째 카드 표시 확인. 기존 맛집의 주소·코멘트·사진 순서 수정과 공개 화면 반영 확인 후 원래 값 복원. 임시 항목 삭제 후 10곳 복구·업로드 파일 제거 확인. 별도 임시 Git 저장소에서 데이터와 사진만 커밋·푸시하고 변경사항 없음·다른 코드 커밋 차단 상태 확인
자동 검사`npm test` 3건 통과, `npm run build` 성공. 공개 빌드에 관리자·비밀 파일 없음
사진 패키지사용자 승인 패키지 21장과 첨부 사진 8장을 10곳에 연결. 10번은 이번에 첨부한 메뉴판 사진 2장 사용
카카오맵 앱지도 링크 생성 확인. 휴대폰에서 앱 자동 전환은 아직 확인하지 않음

사용 방법

  1. 이 Mac에서 `npm start` 실행 후 `http://localhost:4173/admin` 열기
  2. 맛집 정보와 사진을 추가·수정하고 저장
  3. `저장하고 커밋·푸시`를 눌러 공개 사이트에 반영
